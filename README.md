# Movie Explorer

A responsive movie/show discovery web application built with React and Tailwind CSS using the TVMaze API.

## Features

- Browse TV shows from the TVMaze API
- Search shows by title
- View show details in a modal
- Navigate between pages using React Router
- Responsive design with loading and error states

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Technologies

- React
- JavaScript
- Tailwind CSS
- React Router
- TVMaze API
- Vite

## API

Show data is provided by [TVMaze](https://www.tvmaze.com/api).
